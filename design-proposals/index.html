釣りすごろく マップ改善案 5案

密集解消・ゴール可視化・双六らしい流れの強化を狙った概念設計（v3.1.x 検討用）

PROPOSAL A

等距離リフロー（現状ベース）

日本列島の輪郭を保ちつつ、近接ノードに最低距離(60px)を保証する物理シミュレーションで再配置。密集が完全になくなる最小コスト案。

既存実装の延長で済む / 地理が直感的 / 短期で実装可能
力学リフロー導入で実装やや複雑 / 北海道〜九州の縦幅が長い
PROPOSAL B

ジグザグ伝統盤（リニア）

スタート→ゴールを左右に蛇行させた古典的すごろくの版面。地理は捨て、マスを規則的に配置。マスの中身（地名）で日本列島を感じさせる。

完全に重なりなし / すごろくらしい流れ / 子供にも分かりやすい / ゴールが常に見える
地理感が消える / 既存ボードグラフ(207ノード/261エッジ)の再設計が必要 / 海路・分岐の演出が落ちる
PROPOSAL C

環状47道府県（リング）

外周に都道府県を環状配置し、内側にショップ/イベント/休憩のショートカット。中央に図鑑ステータス。すべてが均等に表示され密集ゼロ。

完全に均等配置 / ゴールが中央付近で常に見える / 図鑑/装備ステータスとの一体感 / ボード規模を縮小可能
日本地図のアイデンティティが弱まる / 47県全表記は文字密度が上がる / 既存edge構造を全捨て
PROPOSAL D

島ホップ（地方=島）

8地方を「島」に分解し、地方内は密に、地方間は橋で疎に。タップで島にズーム、ピンチで全体に戻る。スマホ縦長との相性が良い。

各地方が独立した「ステージ」になり没入感UP / スマホズームと相性◎ / 密集ゼロ / 全体ビューでも全島見渡せる
地方間移動の演出を作る必要 / 既存ナビゲーション(横断地名検索など)が壊れる / 開発工数大
PROPOSAL E

グリッド人生ゲーム風

縦方向のレーンに沿った1マス40pxの規則的グリッド。マスの種類を色とアイコンで識別、分岐は左右ジャンプで表現。ゴールはレーン下端で必ず可視。

完全に重なりなし / 3レーン構造で戦略性UP（最短/寄り道/イベント狙い） / ゴールが常に最下端で明確 / スマホ縦長と完全合致
地理が完全に抽象化 / 日本らしさは地名のみ / 既存全エッジを再設計 / 海/山の演出が線形ガイドに置換
釣りすごろく v3.1.x 検討用 — 案AはCSS/座標調整のみ短期適用可能、B〜Eはボードグラフ再設計が必要。
